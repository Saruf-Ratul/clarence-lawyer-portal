# System Requirements Specification (SRS)

## MVP Functional Modules
1. Dashboard KPIs
2. RM Intake Inbox
3. Client/Property/Case management
4. Forms & Filings PDF generation
5. Status timeline + RM pushback
6. Audit log and RBAC

## Integration
- Bidirectional integration with Rent Manager:
  - Pull submissions into intake
  - Push case status updates
